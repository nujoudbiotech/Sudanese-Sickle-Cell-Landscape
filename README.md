# Sudanese Sickle Cell Landscape 🇸🇩🧬
Molecular Analysis of HBB Gene Mutation E6V rs334 in Sudan

Author: Nujoud Basheer | Al Neelain University | Biotechnology

Overview:
This project analyzes the sickle cell mutation E6V in HBB gene, focusing on Darfur tribes.

Why Darfur?
Darfur has high SCD prevalence 2-3 percent, Messeriya and Rizeigat tribes.

Day 1 Done:
hbb_analysis.py - Parses HBB gene, finds E6V mutation, calculates GC content

Day 2 Next:
Compare HbS vs HbA frequency Darfur vs Khartoum

Goal:
Build portfolio for MEXT Japan 2026 - Stem Cell and Gene Therapy

How to Run:
python hbb_analysis.py
